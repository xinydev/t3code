# Diagnostics and product usage data

This build removes product analytics, trace collection and export, crash reports,
agent feedback uploads, resource sampling, and provider protocol logs from the
running app. It also skips background client activity reports, browser profile
broadcasts, provider usage history scans, and remote repository identity probes.

Pairing keeps client labels and the information needed to manage access. The
environment descriptor uses a generic label unless you set `T3CODE_ENVIRONMENT_LABEL`.
Remote media embedded in chat opens as a link.

Projects, conversations, and attachments still use the app's local storage.
An agent or external integration you choose to use handles its own data and
network requests.
